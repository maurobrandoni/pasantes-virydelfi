## Cómo trabajan desde ahora

Ya no hay pull requests. Este repo es de ustedes: pueden guardar todos los cambios que quieran, directo en `main`, y la web se actualiza sola.

1. **Editen** un archivo en VS Code y guárdenlo (`Ctrl+S`).
2. Abran **GitHub Desktop**. Los cambios aparecen en la pestaña **Changes**.
3. Abajo a la izquierda escriban un resumen corto de lo que hicieron (por ejemplo, `Agrego mi foto`).
4. Toquen **Commit to main**.
5. Toquen **Push origin** (arriba).
6. Esperen **uno o dos minutos** y refresquen la página con `F5`. El cambio ya está publicado.

> **Hagan commits chicos y seguidos.** Un commit por cosa que cambian es mejor que uno enorme al final. Si algo se rompe, es fácil volver atrás.

## Extensión recomendada: Live Server

Instálenla en VS Code ahora, antes del Día 3. Es la que les muestra la página mientras la escriben, sin tener que subir nada.

1. En VS Code, abran extensiones (`Ctrl+Shift+X`).
2. Busquen **Live Server** (autor: *Ritwick Dey*) y toquen **Install**.
3. Clic derecho sobre un archivo `.html` → **Open with Live Server**. Se abre el navegador y, cada vez que guardan (`Ctrl+S`), la página se actualiza sola.

Live Server solo muestra la página en su compu. Para que la vea el mundo hay que hacer commit y push.

## ¿Y Node.js?

**Por ahora no hace falta.** HTML, CSS y JavaScript funcionan directo en el navegador, y GitHub Pages publica los archivos tal cual están. Para ver los cambios mientras escriben alcanza con la extensión **Live Server** de VS Code, que se explica en el [Día 3](dias/dia-03.md).

Node.js sirve más adelante, cuando quieran usar herramientas que "arman" la página (como React). Cuando llegue ese momento se instala en diez minutos.

## Glosario

| Palabra | Qué significa |
|---|---|
| **Repositorio (repo)** | Una carpeta de proyecto guardada con todo su historial |
| **Git** | El programa que registra los cambios |
| **GitHub** | El sitio web donde se guardan los repos |
| **GitHub Desktop** | El programa para guardar y subir cambios con botones, sin escribir comandos |
| **Commit** | Guardar un cambio con un mensaje que lo explica |
| **Push** | Subir tus commits a GitHub |
| **GitHub Pages** | El servicio de GitHub que publica una página web a partir de los archivos del repo |
| **HTML** | El lenguaje que dice qué hay en la página (títulos, textos, imágenes) |
| **CSS** | El lenguaje que dice cómo se ve (colores, tamaños, tipografía) |
| **JavaScript** | El lenguaje que hace que la página reaccione (botones, cambios) |
